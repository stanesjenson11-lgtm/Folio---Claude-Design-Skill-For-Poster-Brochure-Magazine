# Changelog

- 0.9.0 (2026-09-30, guided flow) · `reference/wizard.md`: one guided flow for every new magazine, brochure, company book or poster, on Claude Code (plan mode, `/folio:new`, `/folio:magazine`, `/folio:brochure`, `/folio:poster`) and on claude.ai (plain words, chat approval): scan everything first, then three short rounds (logo · what · words → colour palettes suggested from the logo with reasons and the styles each suits · kind · photos → style ranked for the content · contacts · pages), a page plan with every photo placed, a first look (cover + first spread), a still-to-fill list for Canva, saved client brands · styles only from the kit catalogue or a mix of two kits · learn gate: a reference is copied 1:1 but joins the catalogue only when it beats the closest kit (default: not added) · `best_for` on every kit · `/folio:magazine` is now the guided flow and the Ivory style moved to `/folio:ivory` · `kit.py`: a folio home (`FOLIO_HOME`, `$CLAUDE_PLUGIN_DATA` or `~/.folio`) for user-saved kits, taste and brands, so plugin updates keep them; user kits get a personal `/folio-<name>` command; `save --builtin` (automatic in the git checkout) for the shipped catalogue; `kit.py home` · README: how a job flows, where to use it (Claude Code vs claude.ai) · `/folio` with or without content starts the guided flow by default and enters plan mode itself (no `/plan` needed); `/folio:setup` adds a personal `/folio` command, since plugin skills are always namespaced (`/folio:folio`) · `plugin.json` carries no version, so installs with auto-update track every commit.
