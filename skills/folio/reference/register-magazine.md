# register — magazine (magazines, zines, lookbooks, sports/fitness/lifestyle features, event programmes)

Reader: browsing for pleasure. Energy, surprise and pace are the product; each spread should feel like a different room of the same house.

**Typical flatplan:** cover (masthead, cover star, 3–5 cover lines, issue/date, barcode area) · contents · editor's letter · short front section (news, gear, tips — denser pages) · 2–4 features (opener spread + continuation pages) · regular sections · back page.

**Moves that work (see library):** cut-out hero over or behind the masthead/headline (type-behind-subject); two-tone headlines (light small line + heavy huge word in accent colour: "WORKOUT / TIPS"); stacked outline type repeating a word; full-bleed feature openers with the headline set into the photo's quiet area; numbered tips with big display numerals; vertical spine titles; pill tags ("Pro Look", "Get Started") as a deliberate UI-flavoured accent — once per spread, not everywhere; rounded image corners are acceptable here *if* they are the book's motif; editor's signature.

**Tone levers:** dark or saturated pages alternate with paper-white pages; one loud accent (amber, acid yellow, blaze orange) against black/navy; condensed or ultra-heavy grotesk display in caps; tight tracking on display; photo treatment unified (dramatic side-lit, desaturated backgrounds, high contrast).

**Pitfalls:** every page dark (fatigue — keep a light:dark rhythm); too many fonts; cut-outs with halo edges (clean masks or use the Canva/Adobe background-removal tools); body text on busy photos; cover lines that bury the cover star's face.

**Cut-outs:** need a clean alpha PNG. Options: the user's own cut-out, `rembg` (`pip install rembg`, downloads its model from GitHub), or Canva/Adobe background removal via their connectors. Place cut-outs with `.ph.cutout` and let them overlap display type with `data-allow-overlap`.
