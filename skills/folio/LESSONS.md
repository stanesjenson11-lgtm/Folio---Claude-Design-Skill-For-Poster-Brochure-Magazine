# Lessons — symptom → cause → fix

Defects this skill has already hit. Read before building; add to it whenever the self-improvement loop (SKILL.md) finds a defect that would recur. Write generically: no client names or figures.

- **A page-specific override does nothing** (e.g. a running head still sits over a photo) → `.page:nth-of-type(odd) .furniture` in folio.css has higher specificity than `.p5 .furniture` → scope overrides as `.page.p5 .furniture` in a style block that loads after folio.css.
- **Tables grow tall with huge empty rows** → a table placed as a grid child of `.live` stretches to its grid area → folio.css sets `align-self:start` on tables/figures in `.live`; keep it if you override grid rules.
- **A circular portrait vanishes into the binding** → masked shapes placed off the *spine* edge get swallowed by the binding → put masked shapes on the outer edge (recto: right, verso: left); preflight's `spine-mask` check catches it.
- **A stripe or label disappears in the editable/Canva version** → it was drawn with `::before`/`::after`, which cannot be exported → use a real element; editable.py lists every visible pseudo-element.
- **Body text in the editable file falls back to Times** → font names containing spaces were quoted with `"` inside a `style="…"` attribute → editable.py converts quotes; if you hand-write inline styles, use single quotes for font names.
- **Flex rows (page furniture, contact bands) collapse into one run of text in the editable file** → a flex container was treated as a paragraph → editable.py recurses into flex/grid containers; keep text inside real child elements.
- **Photo crops from an old PDF include captions, GPS stamps or slivers of other photos** → a placement box is not the visible area → use `harvest.py`: prefer the native full image and re-crop, and look at `crops.png` before using any crop.
- **Contact-sheet / reel frames show pages in the wrong spread order** → page 1 is a recto; spreads are (2,3), (4,5)… → keep the cover alone; never start interior spreads on an odd page.
- **A script crashes with `UnicodeEncodeError: 'charmap'` on Windows** → the console defaults to cp1252 and can't print ■ — “ → every script sets `sys.stdout.reconfigure(encoding="utf-8")` in its `__main__` block; keep it in new scripts.
- **`--copy` reports client sentences missing after `polish`** → polish turned straight quotes into curly ones, so the sentence no longer matched → preflight's `norm()` folds quotes before comparing.
- **fonts.py downloads nothing on Windows** ("0 files" for every family) → `npm` is `npm.CMD` and can't be launched by bare name, and Google Fonts serves a single TTF without subset comments to a truncated user-agent → fonts.py resolves npm with `shutil.which` and sends a full Chrome UA.
- **Editable export crashes with `OSError: Invalid argument: '\C:\…'`** → `file:///C:/…` was turned into a path by hand → editable.py uses `url2pathname`; SVG files in `<img>` are embedded as vectors (PIL can't open SVG).
- **A translucent inline SVG vanishes in the editable file** → its opacity was applied twice (as an attribute on the SVG and on the exported element) → editable.py drops the root attribute.
- **Preflight flags a vector texture as low-res, and `data-no-folio` is ignored** → SVGs have no pixels to measure; a bare attribute reads as "" (falsy) in `dataset` → preflight skips SVGs in the ppi check and uses `hasAttribute`.
- **Posters in the contact sheet are scattered with gaps** → `--single` pages were placed in half-spread slots → one slot per sheet.
- **"1st Floor" prints as "Ist Floor"** → some display serifs (Marcellus) draw the figure 1 like a capital I → check digits in every face before setting numbers in it; set numeric lines in a face with clear figures.
- **The user rejects a whole variant set as "generic" or picks one** → variants were four unrelated styles with no memory of past verdicts → read `library/TASTE.md` before designing, build variants inside the loved family, and record every verdict (`reference/taste.md`).
- **A headline reads sideways or upside-down** → `writing-mode: vertical-rl` (or `rotate(180deg)`) on a big title → keep headlines horizontal; preflight `rotated-heading` flags text ≥ 30pt set this way.
- **A label sits inline next to its value in the Canva file** → a `<span>` inside a paragraph was set to `display: block`; the editable export keeps paragraphs as one text box → put label and value in separate `<p>` elements.
- **Paper or grain overlays trigger low-res, duplicate-image and monotony warnings on every page** → preflight measured the texture as a photo → mark texture containers `data-texture`.
- **Layered elements swap order in the Canva file** (a photo covers the headline that sits on top of it in the PDF) → the editable export listed elements in DOM order and ignored `z-index` → editable.py records each element's stacking path and sorts by it.
- **An organic blob is sliced flat along one side** → the blob ran past its own SVG canvas and `object-fit: cover` cropped it → imagery.py keeps blobs inside the canvas; show blob art with `object-fit: contain`.
- **Wave-edged photo frames come out mirrored or jagged in Canva, or the export crashes** → minus signs were stripped from polygon points, `evenodd,` or `calc()` broke parsing, and masks weren't anti-aliased → mask_image keeps signs, skips what it can't read, draws at 4× and box-downsamples; generate masks with `imagery.py mask` (plain % pairs).
- **Text on a pill or chip fails contrast at 1:1** → preflight measured the colour behind the chip, not the chip's own background → it checks the element's own background first.
- **Text on a wave band loses contrast at the crests** → the band's wave rose into the text block → set the liquid `--level`/`--amp` so the front band's highest crest stays below the text.
- **Two poster variants feel the same** → both put the headline in the same place → preflight `variant-clash`; move one header (top · left edge · bottom · centre) until the check is quiet.
- **Palette suggestions look neon or random** → maximal-chroma complements read as UI colours → palette.py keeps generated accents muted (OKLCH C ≈ 0.08–0.12) and prefers brass/metallic accents for dark brands.
- **The client says the lines under headings and list items make it look AI-made** → hairline rules were used as separators everywhere (contents, indexes, above text, over empty space) → separate with space, type size and colour fields; preflight `rule-heavy` flags single borders and thin bars.
- **The piece reads as two colours** → the palette had paper + ink + one accent used on tiny details → pick a support colour and give it real area (a field, a band, big numerals); preflight `palette-thin` counts visible colours with images hidden.
- **Small text on the sage field fails contrast in both ivory and espresso** → mid-lightness support colours sit near 3–4.5:1 with every palette neutral → put only large type (18pt+) on them, keep labels and folios off them (move folios to the head when a band bleeds at the foot), use champagne for boxes that carry small text.
- **The same ground photo shows twice across a spread** → each page had its own full-bleed copy → put the ground in one `.cross` element spanning both pages.
- **A sketch shows a faint straight line along its top or bottom** → the edge blur leaked to the canvas edge on wide crops → imagery.py fades the outer 5% of the sketch alpha to zero (doctest checks the border).
- **The cut-out person loses the laptop in his hands** → the human-segmentation model keeps only the body; the general model keeps props but fades the legs → `cutout --person` takes the union of both masks.
- **Photos look cold next to a warm palette** → white-desk stock photos are blue-grey → grade them with `--treatment tint --brand <accent>`, and mute rainbow subjects (swatch fans) before placing.
- **A tech company's brochure shows coffee cups and notebooks** → images were picked for mood, not subject → list the subject's nouns first (computers, its own site on devices, AI, robots, code, servers) and source only those; screenshot the client's site into a device mockup.
- **Fidelity drops 1–3% on some pages of a custom-size document** → the original's pages sit on fractional device pixels, the editable's on whole ones, so every edge differs by half a pixel → the checker compares at the best half-pixel alignment.
- **A tilted image comes out upright in the Canva file** → CSS transforms on images are not reproduced by the editable export → bake the rotation into the file (`Image.rotate(angle, expand=True)`) and place it untransformed.
- **White titles or labels on bright teal, orange or yellow fail contrast** → mid-light brand colours can't carry white → deepen the field until white reaches 3:1 for large type, set small text on fields in ink, and replace white-on-yellow with a deep accent (burnt orange).
- **Body text on landscape single pages is flagged as a common font in a display role** → preflight treats `.single` pages like posters → use the aesthetic sans (Wayfinder CF → Familjen Grotesk) for body on single pages.
- **A straight line appears just under a flowing colour edge** → a texture layer was clipped to a rectangle next to the wave → drop the texture there or let it cover the whole page.
- **A floating phone on the cover shows other companies' apps** → a stock phone screenshot carries third-party brands → make the hero device from the client's own screens (`imagery.py screenshot` + `mockup`).
- **A 1:1 replica is judged 'not like the image'** → only some spreads were built and the headings used a lighter face than the reference → build every spread the reference shows, match type weight (a heavy face with `font-variant-caps: small-caps` when the reference uses heavy small caps; the editable export keeps it), and check a side-by-side sheet before delivering.
- **A faint background photo turns the Canva page grey** → it sat in a `.ph` photo frame, whose tint background the export does not fade with the frame's opacity → put faint grounds in a `.fill` div marked `data-texture`.
- **`palette-thin` fires on a black-and-white page set whose colour is in its photos and big type** → it measured pixel area with photos hidden → it now also counts display-type colours (20pt+); photo-led styles can mark `<html data-palette-photos>`.
- **A tilted band exports straight, off-position, with its text unrotated in the Canva file** → the exporter measured the transformed bounding box and applied the transform again, and children lost their parent's rotation → editable.py measures transformed boxes untransformed and gives every piece inside them the box's transform with its origin in the piece's own coordinates.
- **A white graffiti or display word appears to cut through a tape or band in front of it** → it is stacked above the band (or the band above it) by accident → set explicit `z-index` on layered cover pieces (band, word, barcode) so the order is intended.
- **Background shell jobs write files into the wrong folder** → `cd dir && curl … &` runs the `cd` in the background subshell only; later commands stay in the old folder → never background a command that starts with `cd`; use absolute paths for parallel downloads.
- **The Canva-editable file is 20–70 MB and slow or impossible to import** → every photo and cut-out was embedded at up to 4x CSS resolution as full-colour PNG, with every font subset → editable.py keeps a size budget (8 MB): it steps image resolution down (never below 192 ppi), palette-encodes the largest transparent images, embeds only the Unicode subsets the text uses and stores noise textures at low resolution; no element is dropped.
- **A decorative ghost word fails the contrast check** → preflight treated it as text to read → mark ornamental text `aria-hidden="true"` (and `data-allow-overlap` when it sits behind other text); preflight then reports it as decorative.
- **A guessed stock-photo ID overwrites a good photo with an error page** → the download URL was built from an ID that was never looked up → only download IDs or URLs taken from a search result, and check the file opens before replacing anything.
- **One photo looks washed out in the Canva file (and in crops made from it) but fine in the PDF** → the JPEG carries a ProPhoto or Adobe RGB profile that the browser applies and PIL ignores when it re-encodes → editable.py and imagery.py convert embedded non-sRGB profiles to sRGB before cropping or grading.
- **A magazine is called 'too plain' or 'too empty'** → pages were clean white with separate pages side by side → layer every page (paper grain, tinted panels, faint background words), fill it to the reference's density, and carry one element across the fold on every spread (`.cross`).
- **`kit.py new` crashes writing a texture (cannot write RGBA as JPEG)** → `save` matched 'paper' anywhere in a file name, so the photo `team-papers.jpg` became a paper-texture recipe → textures are matched as whole name parts (`paper.png`, `paper-ivory.png`, `grain-espresso.png`), and a re-save removes a stale `textures.txt`.
