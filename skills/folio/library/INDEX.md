# Folio library

The library is folio's growing design memory. Patterns are layout moves (what a page or spread does); directions are whole-book lanes (colour strategy, type behaviour, motif, photo treatment). Everything here was distilled from reference boards — grammar, never artwork. Add to it with `refs`.

Read this index and `HOUSE.md` (the studio's own house style, distilled from its past work), then open only the cards your flatplan uses.

## Families at a glance
- **cover:** arc-window, drench-cover, slab-cover, cutout-masthead
- **opener (loud):** full-bleed-opener, band-stack, split-panel
- **contents:** numbered-index
- **text:** quote-portrait, offset-block
- **devices (combine with any page):** two-tone-headline, vertical-title, ghost-type
- **data:** stat-spread, data-tint, numbered-sequence, map-reach
- **gallery:** mosaic, photo-strip
- **profile:** circle-portraits
- **closer:** back-cover
- **poster (single sheets and series):** speaker-poster, series-rail, numeral-window, bilingual-lockup (see `reference/formats.md`)
- **catalog data:** product-cell-grid, spec-sheet-frame, layer-section
- **quotation:** quote-cover, estimate-sheet
