# Numbered sequence

**Why it works:** Steps, tips, milestones or strategic pillars set with big display numerals and short text, joined by a rule or a line of circles. It's legitimate numbering because the order carries meaning.

**Anatomy**
```
01 ── Stretching for flexibility      (numerals 24–40pt, accent)
       two lines of text               (rule between items)
 02 ── Post-workout recovery
       …
 ◉──◉──◉   timeline variant: circles on a line, labels under
```

**Rules**
- Use only for a real sequence (steps, years, ranked items).
- 3–6 items; more becomes a list.
- Numerals align on a shared baseline or a shared left edge.

**Goes generic when**
- Numbering every section of the book by reflex.
- Numbers in circles with icons inside them.

**Build notes:** Grid rows in `.live`; timeline as flex with a pseudo-element line.
