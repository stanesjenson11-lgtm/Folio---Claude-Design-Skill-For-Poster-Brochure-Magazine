# Letter-disc title

**Why it works:** A solid disc behind the first capital marks every page title with one repeatable, brand-coloured gesture, so a set of pages reads as a family.

**Rules**
- Disc diameter ≈ 1.6 × cap height, centred on the first letter's left half; title in heavy caps over it.
- Disc colour contrasts with both the ground and the letter (orange disc on teal with white type; teal or orange disc on white with ink type).
- Build it as a separate round element behind the text (`data-allow-round`), so Canva keeps it.
